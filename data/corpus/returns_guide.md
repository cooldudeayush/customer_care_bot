# ShopMate Returns Guide

## How to start a return
1. Returns can be started within the same window as refunds: **30 days** for most
   items, **15 days** for electronics, counted from the delivery date.
2. The item must be in its **original condition** with tags and packaging where
   applicable.

## Return shipping costs
- **Free return shipping** is provided when the item is **defective, damaged, or
  the wrong item** was sent.
- For **change-of-mind** returns, the customer pays return shipping, except for
  **Premium members**, who get free return shipping on all returns.

## Return condition requirements
- Items must be unused and undamaged beyond normal inspection.
- Opened software, activated SIM cards, and used hygiene products cannot be
  returned unless defective.

## Exchanges
- You may exchange an item for a different size, color, or variant within the
  return window, subject to availability.
- If the exchanged item costs more, you pay the difference; if it costs less, the
  difference is refunded to your original payment method.

## Refund after return
- Once we **receive and inspect** the returned item, the refund is approved and
  processed within **3–5 business days** to the original payment method.

## Non-returnable items
- Perishables, gift cards, downloadable products, and final-sale items are not
  returnable unless they arrived damaged or defective.
